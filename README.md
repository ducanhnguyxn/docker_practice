Docker Practice 🐳

A hands-on repository for learning and practicing Docker, from basic commands to containerizing applications.

🎯 Learning Goals

* Understand Docker and containerization.
* Learn to create and manage containers.
* Build custom Docker images using Dockerfiles.
* Map ports and manage volumes.
* Use Docker Compose to run multiple services.
* Practice containerizing backend applications.

🛠️ Technologies

* Docker
* Docker Compose
* Node.js
* Linux

📚 Topics Covered

* Docker installation and basic commands
* Images and containers
* Writing Dockerfiles
* Port mapping and volume mounting
* Environment variables
* Docker networking
* Docker Compose
* Containerizing a Node.js backend

🚀 Goal

Build practical Docker skills by creating, running, and managing containerized applications.
